# Pacific Pain Clinic — Homepage Concept

A responsive, static concept site for Pacific Pain Clinic. Built with semantic HTML, modern CSS, lightweight SVG/CSS animation, and vanilla JavaScript so it can be hosted directly on GitHub Pages.

## Notes

- The appointment form is intentionally a non-submitting concept form.
- Contact details are based on the current site's homepage and must be verified before production use.
- Motion is reduced automatically when the visitor enables the system “Reduce motion” setting.
